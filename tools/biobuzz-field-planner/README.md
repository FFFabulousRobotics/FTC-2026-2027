# BIOBUZZ 场地坐标与自动路线规划器

直接用浏览器打开 `BIOBUZZ-field-planner.html`，这是包含底图的单文件版本，也可单独复制到其他位置。开发版入口是同目录 `index.html`，修改源码后运行 `python build.py` 重新打包。无需联网、安装软件或启动服务器，配置会保存在浏览器本地；也可以保存/载入 JSON 方案。

## 使用

1. 输入实际车长、车宽；定位参考点不是车体中心时，填写前/左偏移。
2. 点选坐标原点与 +X 方向，或把机器人放在预期起点，点击“以当前机器人位置和朝向归零”。+Y 在 +X 左侧，朝向逆时针为正。
3. 点击或拖动机器人，查看本地 x/y/heading。改变坐标系不会移动已有路线的物理位置。
4. 用“添加参考点”标记射击框等目标；用“添加路点”规划机器人参考点路径。点选列表后可精确编辑位置与朝向。
5. 可手动布线，也可“首尾自动绕障”。后者会替换中间点，采用保守圆包络；较窄的实际可通行路线需手动布局并检查旋转外形。
6. 播放预览、检查碰撞，再导出 `PlannedRoute.java` 或坐标片段。Java 均为英寸坐标、弧度朝向，适用于当前项目的 Pedro 2.1.2。

导出路线只描述几何路线与朝向，不包含吸球、射击、等待等状态机动作。匀速估时不包含加减速、纯转向时间、机构动作及停车误差。

- 第 51–52 页：装载区 23×11 in、花园 23×2 in；图 9-2、9-4 用于确认方向和接缝位置。红方在左，蓝方在右，观众侧在下方。
- 第 54–56 页：中央框架底部最大包络宽 49.46 in、深 38.95 in；蜂巢中心线间距 25.5 in。
- 第 57–58 页：花朵开口直径 4 in。墙内深度默认 4.8 in 是可修改的保守近似，切向包络取图示 2.40+1.89=4.29 in；并非经过 CAD 验证的完整碰撞模型。

## 模型限制

中央框架默认整块底部包络避障，未建模其下方三维净空。蜂房倾倒后开口位置会改变，因此不自动生成射击目标中心。装载区/花园为地面标记，不作为实体障碍。

碰撞检测按旋转矩形外形与留边检查围墙和固定障碍，路线每 ≤0.5 in、转角每 ≤2° 采样。自动绕障使用参考点到机器人最远角点的圆包络、2 in 网格 A*、线段简化。它提供保守的二维几何方案，不保证三维通行、动态避障、比赛规则合法或真实机器人跟踪误差下的安全。

用户场地原点与此前实测坐标的对应关系必须由现场设定；工具不会将此前 Position.java 中的坐标强行映射到手册场地。
